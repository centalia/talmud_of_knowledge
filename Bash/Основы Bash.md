
Bash (shell) — это не только интерфейс между пользователем и ОС, но и язык для скриптов. В скриптах доступны все UNIX‑команды, утилиты и встроенные конструкции Bash (условия, циклы и др.) — это делает их удобными для автоматизации админских задач.

## Зачем нужен Bash

Bash — стандартная командная оболочка и язык скриптов для UNIX‑систем. Он прост в освоении, хорошо подходит для администрирования (в том числе для правки стартовых скриптов в `/etc/rc.d`) и быстрого прототипирования: позволяет разбить сложную задачу на простые шаги в духе философии UNIX «разделяй и властвуй».

## Где Bash не стоит применять

Не подходит для задач, где важны:

- высокая производительность и работа с большими объёмами данных;
- сложные математические вычисления;
- строгая структура и контроль типов;
- графический интерфейс, прямой доступ к железу, работа с сокетами и портами;
- безопасность и закрытость кода;
- кросс‑платформенность.

В таких случаях лучше использовать Python, Perl, C, C++ и другие языки, но Bash всё равно может пригодиться для прототипа.

## Практические детали

- Bash (Bourne‑Again Shell) вобрал в себя многие особенности других оболочек (например, ksh).
- Скрипты обычно сохраняют с расширением `.sh`.
- Для запуска нужно выдать файлу права на исполнение: `chmod u+rx scriptname.sh`.

Чтобы запустить несколько команд в терминале можно использовать `;` 

```
whoami; date
```

Это позволяет выполнить простые операции в одну строку, а не вызывать каждую по отдельности. Все команды выполняются последовательно, не зависимо не результата операции.
## Как создать shell-скрипт

Вводить длинные цепочки команд в терминале не удобно, для этого был придуман shell-скрипт, файл где хранится вся цепочка команд.
