### Комментарии `#`

 Строка, начинающаяся с `#` .
 
 ```
 # Это сторока - комментарий
 ```

 Комментарии, могут располагаться в конце строчки кода

```
echo "В конце строки комментарий" # Это комментарий
```

Комментариям, могут предшествовать табуляции (пробелы, знак табуляции)

```
 # Перед комментарием стоит пробел
```

Исполняемые команды не могут следовать за комментарием в той же строке. 

Само собой разумеется, экранированный символ `#` в операторе `echo` не воспринимается как начало комментария. Более того, он может использоваться в операциях подстановки параметров и в константных числовых выражениях.

~~~
echo "Символ # не означает начало комментария."
echo 'Символ # не означает начало комментария.'
echo Символ \# не означает начало комментария.
echo А здесь символ # означает начало комментария.

echo ${PATH#*:}       # Подстановка -- не комментарий.
echo $(( 2#101011 ))  # База системы счисления -- не комментарий.
~~~

Одинарные и двойные кавычки и обратный слеш могут отменить действие знака `#`
### Разделитель команд `;`

Разделитель команд позволяет запустить несколько команд в одной строке.

```
whoami; date
```

Это позволяет выполнить простые операции в одну строку, а не вызывать каждую по отдельности. Все команды выполняются последовательно, не зависимо не результата операции. Символ `;`, иногда следует так же как и `#` экранировать
###  `;;` — Конец ветки `case`

Завершает блок в конструкции `case`. Без него bash перейдет к выполнению следующего блока (fall-through).

``` bash
case "$1" in
  -h|--help)
    echo "Справка"
    ;;
  *)
    echo "Неизвестный флаг"
    ;;
esac
```
### `$@` — Все аргументы скрипта/функции

Передает все аргументы как отдельные слова. Используется в функциях.

```bash
my_func "$@" # Передаст функции все аргументы, с которыми вызвали скрипт
```

### `shift` — Сдвиг аргументов

Удаляет `$1` и сдвигает все остальные влево (`$2` становится `$1`). Незаменим в циклах `while` при парсинге флагов.

``` bash
while [ $# -gt 0 ]; do
  echo "Обрабатываю: $1"
  shift # Переходим к следующему аргументу
done
```
