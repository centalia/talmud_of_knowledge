### Комментарии `#`

 Строка, начинающаяся с `#` .
 
 ```
 # Это сторока - комментарий
 ```

 Комментарии, могут располагаться в конце строчки кода

```
echo "В конце строки комментарий" # Это комментарий
```

Комментариям, могут предшествовать табуляции (пробелы, знак табуляции)

```
 # Перед комментарием стоит пробел
```

Исполняемые команды не могут следовать за комментарием в той же строке. 

Само собой разумеется, экранированный символ `#` в операторе `echo` не воспринимается как начало комментария. Более того, он может использоваться в операциях подстановки параметров и в константных числовых выражениях.

~~~
echo "Символ # не означает начало комментария."
echo 'Символ # не означает начало комментария.'
echo Символ \# не означает начало комментария.
echo А здесь символ # означает начало комментария.

echo ${PATH#*:}       # Подстановка -- не комментарий.
echo $(( 2#101011 ))  # База системы счисления -- не комментарий.
~~~
### Разделитель команд `;`

Чтобы запустить несколько команд в терминале можно использовать `;` 

```
whoami; date
```

Это позволяет выполнить простые операции в одну строку, а не вызывать каждую по отдельности. Все команды выполняются последовательно, не зависимо не результата операции.
